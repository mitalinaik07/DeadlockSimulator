DEADLOCK STRATEGIES OVERVIEW
What is a Deadlock?

A deadlock occurs in an operating system when a set of processes are blocked because each process holds a resource and waits for another resource held by some other process in the set.

Avoidance

Requires prior knowledge of maximum resource demands. Before granting a request, the system dynamically checks if the resulting state remains safe (e.g., Banker's Algorithm).

Detection

Allows processes to request resources freely. The OS periodically runs an algorithm (like RAG cycle check or Tarjan's SCC) to inspect graph cycles and identify deadlocked processes.
